Correcting a transcript is a two-handed job: one hand on the audio, one on the text. Everything below exists so neither hand has to reach for the mouse.

## Playback

| Shortcut | Action |
| --- | --- |
| `Space` or `Tab` | Play / pause |
| `Alt/Ctrl + Space` | Play / pause while editing text |
| Hold `Alt` | 0.5× speed |
| Hold `Ctrl` | 2× speed |
| Hold `Alt + Ctrl` | 4× speed |

## Navigation

| Shortcut | Action |
| --- | --- |
| Arrow keys | Move word by word |
| `Shift` + arrows | Move sentence by sentence |
| `Enter` | Enter edit mode |
| `Escape` | Exit edit mode |

## Formatting

| Shortcut | Action |
| --- | --- |
| `⌘B` | Bold |
| `⌘I` | Italic |
| `⌘U` | Underline |
| `⌘⇧X` | Strikethrough |
| `⌘⌥M` | Comment |

## Your own shortcuts

You can bind a key combination to a piece of text — a recurring name, a code, a transcription convention like `[inaudible]`. Custom shortcuts are stored on your account and follow you across documents and devices. Manage them from the shortcuts dialog in the document actions.

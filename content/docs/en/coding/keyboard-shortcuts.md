**There are no coding shortcuts yet**: applying codes to passages is not shipped. This page says what is coming, so you know what to expect from the workflow.

## What already works

Everything in the editor. Selecting passages, moving through the transcript sentence by sentence, playing the audio while you read, the shortcuts in [Keyboard shortcuts](/docs/transcribe/keyboard-shortcuts) are the same ones you will use to select what you are about to code.

The custom shortcuts are worth knowing about now: you can already bind a key to a piece of text, which is how some people mark passages by convention (`[theme:trust]`) while waiting for real coding. It is a workaround, not a system, those marks are text, not data, but it keeps a first pass moving.

## What is planned

Coding is only fast if a code is one keystroke away. The intent is:

- A number key per code in the active codebook, applied to the current selection.
- Repeat-last-code, for the long stretches where one theme dominates.
- Undo that removes a code without touching the transcript.

Nothing above is final. If you code for a living and have opinions about what those keys should be, the feedback button in the app reaches us directly.

**Codes are not part of any export yet.** Coding is being built; codebooks exist, applying codes to passages does not, and there is therefore nothing coded to export.

This page describes what to do in the meantime, and what will land when coding does.

## Coding elsewhere, for now

Export the transcript and code it in the tool you already use:

- **NVivo** or **MAXQDA**, imported as a proper transcript, with speakers and timings, so your codes attach to real passages rather than to a wall of text.
- **CSV**: one row per segment; a coding column in a spreadsheet is a perfectly respectable method for a small corpus.

See [Export](/docs/transcribe/export) for the full list and the text options.

Nothing about this is a dead end: transcripts corrected here keep their value wherever you code them, and the codebooks you define here will apply to the same documents when coding ships.

## What is planned

- Codes carried into the NVivo and MAXQDA exports, so a coded corpus moves in one piece.
- A CSV of coded segments, code, passage, speaker, timing, document, for statistics and scripts.
- Codebook export and import, to share a grid between projects or with a co-coder.

If you have a format your team depends on, tell us through the feedback button in the app: this is exactly the kind of decision that is cheap to get right before it is built.
